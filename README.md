# SimpleCRM

A simple, frontend-only CRM built with React, TypeScript, and Vite. No backend or database — all data is hardcoded fake data for demo purposes.

## Features

- **Dashboard** — pipeline value, win rate, top open deals, and recent activity at a glance
- **Contacts** — searchable contact list with a detail view showing related deals and activity
- **Pipeline** — kanban-style board of deals grouped by stage (New, Contacted, Proposal, Negotiation, Won, Lost)

## Getting started

```bash
npm install
npm run dev
```

Then open the printed local URL in your browser.

## Tech stack

- React 19 + TypeScript
- Vite
- Plain CSS (no UI framework)
